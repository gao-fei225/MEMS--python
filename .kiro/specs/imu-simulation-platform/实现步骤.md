# 仿真真值闭环平台实现流程文档（无标定器械 / 无严格温控条件）

## 1. 文档目的与交付目标

### 1.1 目的
在缺少企业级标定器械、缺少严格温控环境的前提下，搭建一套“仿真真值闭环平台”，用于：
- 生成可控真值（姿态/角速度/非重力加速度/温度轨迹）
- 合成与实测结构一致的 IMU 观测数据（acc/gyro）
- 在统一数据集上评估 baseline 与自适应 EKF（对比、消融、敏感性）
- 输出可迁移的“参数配置包”（推荐参数区间、适用边界、稳定性边界）

### 1.2 最终交付物（Definition of Done）
完成后你应能“一键运行”得到：
1) `data/generated/*.npz`：仿真数据集（含 truth/meas/meta）
2) `outputs/figures/*.png`：关键图（真值vs估计、误差、NIS、λ/R_acc）
3) `outputs/tables/*.csv|json`：对比表、消融表、敏感性结果
4) `outputs/config_packs/<pack_name>/`：可迁移配置包（yaml + 适用边界说明 + 期望性能）

---

## 2. 工程原则（避免返工的关键）

### 2.1 先“契约”后“实现”
先固定三类契约：
- 坐标系与姿态表示（frames & conventions）
- 数据字段结构（dataset schema）
- 模块接口（truth → sensors → filters → metrics → experiments）

然后立刻做一个最小可用闭环（MVP），再逐步扩展复杂度。

### 2.2 每次只加一种复杂度
扩展顺序建议：
- 先加工况（swing → accel → turn → vibration → shock）
- 再加误差模型（bias RW → 温漂 → scale/misalignment → 饱和/量化）
- 最后加自适应机制与一致性检验、参数 sweep

### 2.3 强制回归要求
任何新增功能都必须：
- 可通过 config 开关关闭
- 关闭时与上一版结果一致（或误差极小）
- 开启时能观察到符合预期的现象

### 8.3 必须实现的函数

`src/sensors/error_models.py`

```python
import numpy as np

def add_constant_bias(x: np.ndarray, b: np.ndarray) -> np.ndarray:
    # x: (N,3), b: (3,)
    return x + b[None, :]

def add_white_noise(x: np.ndarray, sigma: float, rng: np.random.Generator) -> np.ndarray:
    return x + rng.normal(0.0, sigma, size=x.shape)
```

`src/sensors/imu_model.py`

    # 2) a_ideal_b = R_bn * a_total_n
    # 3) 注入 bias + white noise

### 8.4 验收标准（必须逐条验证）

用 quasi_static truth：

1. bias=0, noise=0 时：||acc||≈g 且随姿态投影正确

## 13. 扩展工况库（Step 10：每次加一个工况并验收）

### 13.1 新增顺序与最低实现要求

每新增一个工况都要：

* `src/truth/scenarios.py` 增加 `generate_<name>`
* `configs/scenarios/<name>.yaml` 增加模板
* run_one 支持路由

#### (1) swing（摆动）

* r/p 正弦：幅值 A，频率 f
* a_lin_n = 0
* 必须输出 omega_b（由姿态导数得到）

验收：

* run_one 能跑完
* 误差随 A、f 增大而增大（合理趋势）

#### (2) accel（加减速）

* 姿态近水平
* a_lin_n 做阶跃/斜坡/正弦（峰值 a_max）

验收：

* ekf_fixed 的 NIS 在加速段显著升高（符合“量测失配”预期）

#### (3) turn（转弯）

* yaw_rate 给定 + 向心加速度

#### (4) vibration（振动）

* a_lin_n 带限随机（RMS、带宽）

#### (5) shock（冲击）

* a_lin_n 脉冲（峰值、脉宽）

### 13.2 每个工况的统一验收标准

* truth 字段齐全且 shape 正确
* complementary 与 ekf_fixed 都能跑完（允许误差大，但不能崩）
* 输出 dataset + 图 + metrics

2. Step 4~8：准静态闭环跑通（truth→imu→complementary→metrics→run_one）

## 18. 常见失败点与排查顺序（极重要）

1. 坐标系/重力方向写错 → acc 投影不对 → 所有算法全错
2. q_nb 含义不一致（b→n vs n→b）→ R_bn 用错
3. acc_to_roll_pitch 公式与 frames 不一致
4. dt 与 fs 不一致（时间基准错）→ gyro 积分飘
5. EKF 量测模型/单位化策略不一致 → NIS 无意义
6. 自适应更新律没有上下界/回落策略 → 过度膨胀或锁死
